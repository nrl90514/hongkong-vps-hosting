## 香港节点真正值钱的地方

三个实际好处，不是概念。

**一是免 ICP 备案。** 国内节点走完备案流程，快的也要一两周，慢的时候来回补材料能拖一个月。香港机器开通就能用，域名解析过去直接访问。

**二是到大陆的物理距离近。** 香港到内地常见延迟落在几十毫秒区间，公开测评里，三网直连线路的全国平均延迟大致在 45ms 上下。同样的站放到美西，动辄 150ms 起步，后台点一下要等一下的感觉很明显。

## 配置不从「几核几G」开始，从站点类型开始

很多人第一句就问几核几G，这问题没标准答案。倒过来算更快：

| 站点类型 | 建议起步配置 | 说明 |
| --- | --- | --- |
| 静态站 / 展示页 / 个人博客 | 1核1G，系统盘 30GB | 日均几百访客够用，图片多就挂 CDN |
| WordPress + 少量插件 | 2核2G 起 | 1G 跑 WP 加缓存勉强能用，插件一多内存先见底 |
| WooCommerce / 论坛 / 多站 | 2核4G～4核8G | 数据库频繁读写，短板通常在内存和磁盘 IO |
| 图片站 / 下载 / 大流量 | 4核8G 起，看月流量包 | 优先选大带宽限流量型 |

几个容易买错的点。

**内存比 CPU 更容易成为瓶颈。** 内存不够就开始吃 swap，用硬盘当内存用，性能断崖式下跌。WordPress 这类 CMS 加几个插件，2GB 会舒服很多。

**硬盘看类型也看 IOPS。** 都写 SSD，实际随机读写能差好几倍。香港主流配置现在基本都是企业级 NVMe，数据库密集的业务别碰机械盘。

**带宽和流量是两个东西。** 带宽是瞬时速率（Mbps），流量是周期内的累计传输量（GB/TB）。1Mbps ≈ 0.125MB/s，10Mbps 跑满一个月大约 3.24TB。估流量就按「日 PV × 页面大小」，图片和视频要单独算。

## 比配置更容易吃亏的，是线路

这是香港 VPS 最有水分的地方。同样标着「10M 带宽」，CN2 GIA 和普通国际线路在晚高峰完全不是一个体验。

常见的几类：

- **三网直连（CN2 + CMI + CUG）**：电信、联通、移动去程回程都直连，做面向大陆的站最稳。
- **移动优化（CMI）**：移动线路表现突出，电信联通也直连。
- **混合软银线路**：去程直连，回程绕日本，延迟会比纯直连高一截，公开测评里平均延迟能到 95ms 左右。
- **国际大带宽**：出口很大、带宽数字好看，但面向大陆不保证，适合海外访客为主的站。

验线路的方法只有一个：跟商家要测试 IP，在**晚高峰 20:00 到 23:00** 跑 `ping` 和 `mtr`，看平均延迟和丢包；再 `tracert` 看有没有绕美国、绕日本的节点。白天测速漂亮、晚上崩掉的机器，问题基本都在这里。

## 从开机到网站上线：实际要走的步骤

1. **定机房和线路。** 访客主要在大陆，优先三网直连或移动优化线路，别为了带宽数字选纯国际线路。
2. **选配置和计费模式。** 按前面那张表倒推，宁可先把数据库和 Web 服务调顺，也别一上来堆配置。
3. **充值下单。** 余额不足会在下单时提示，支付宝、微信都能充。
4. **装系统或镜像。** 不想折腾命令行的，直接选带宝塔面板的镜像，装完就能进后台建站。
5. **域名解析。** A 记录指向服务器独立 IPv4，生效后就能访问。
6. **部署站点。** WordPress 用官方包或者面板一键安装都行。
7. **配 HTTPS。** Let's Encrypt 免费证书够用，顺便把 HTTP 跳转 301 做上。
8. **开 BBR。** Linux 内核 4.9 以上自带，跨国线路提升明显。
9. **设快照和备份。** 数据库单独设一份定时备份，比事后找客服管用。
10. **收安全尾巴。** 改 SSH 端口、禁用 root 密码登录、装 fail2ban。香港机器面向国际，扫描流量不会少。

## 几个容易被忽略的坑

- **IP 是独立的，但不是原生 IP。** 雨云香港三网直连类产品公开测评提到这点。普通建站没影响，对 IP 纯净度有要求的业务要先想清楚。套餐自带 1 个 IPv4，额外加 IP 是 5 元/个。
- **限速之后的带宽可能不够用。** 5Mbps 大概 640KB/s，图片站和下载站会很难受。
- **异常低价要警惕。** 「1核1G + 100M CN2 + 月付 10 元」这种组合，高峰期大概率掉速，超售是常见原因。
- **VPS 是虚拟化共享。** 同宿主机上邻居跑满，你的体验会受影响。这是 VPS 的固有特性，不是某一家的问题。
- **别只信参数表。** VPS 真正考验人的时候是半夜宕机、流量突然上来、配置改错，售后响应速度比参数重要。

## 常见问题

**香港 VPS 建站要备案吗？**
不用。这也是很多人选香港而不是国内节点的直接原因。

**1核1G 能跑 WordPress 吗？**
能跑。加缓存、控制插件数量，日均几百访客问题不大。但插件一多、并发一上来就会紧，预算允许直接上 2核2G 更省心。

**带宽和流量到底先看哪个？**
访客以文字和图片为主，先看流量额度；有视频或下载需求，两个都得看，并且要确认超额后的处理方式——是限速还是按量收费。

**要不要额外买 IP？**
一个站、一个域名，套餐自带的 1 个 IP 就够了。只有多站需要独立 IP 区分权重时，再加 5 元/个。

**先月付还是直接年付？**
先月付。用一个月券把价格压下来，晚高峰实测过线路和稳定性，再转年付吃 7 折。香港机器最大的不确定性从来不是价格，是线路在高峰期到底稳不稳。
